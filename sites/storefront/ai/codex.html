Add user accounts & cloud storage

Standalone apps use localStorage. If you need platform sign-in, per-user cloud storage, realtime rooms, or a secret-injecting API proxy:

  • Auth — GitHub, Google, Apple, or email (when configured). fas.auth.signIn()
  • KV — Per-user storage. fas.kv.set('key', value)
  • Rooms — Realtime WebSocket. fas.rooms.join('lobby')
  • Proxy — Server-side API keys. fas.proxy.fetch('api.example.com/data')
