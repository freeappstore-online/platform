About FreeAppStore

Free, open-source web apps for everyday tasks. No app subscriptions, ads, or paywalls.

Useful apps, free forever

Browse the catalog for timers, calculators, notes, learning tools, creative apps, and more. Each app runs on its own subdomain in your browser. Apps are published with public source code under the MIT license.

Free to use

FreeAppStore apps take no payments. External APIs you choose to use with your own key can have provider charges; the app should explain those before you connect.

On your device or connected

Standalone apps can keep data on your device. Connected apps can use platform sign-in, cloud storage, public collections, and realtime rooms.

Built for the browser

Apps support responsive layouts and can be installed where the browser supports PWAs. Offline behavior depends on the app; live data, sync, sign-in, and API calls need a connection.

Clear permissions

App listings show requested browser permissions. Read our privacy policy for account data, storage, diagnostics, and integrations.

A shared platform for creators

Creators get a public GitHub repository, HTTPS subdomain, automated deployment workflow, and storefront listing. Publish through the fas CLI or build in VibeCode. Provisioning is self-service; there is no standard 48-hour application queue.

The SDK includes sign-in, per-user key-value storage, public document collections, shared counters, realtime rooms, app roles, friendships, email, scheduled push reminders, API proxying, and an encrypted key vault. React apps use the SDK's Shell, hooks, and UI components. See capabilities and service limits.

FreeAppStore and the sister stores

FreeGameStore hosts browser games, and FreeWebStore hosts one-page sites. They have their own publishing tools and rules.

ProAppStore is a separate paid platform. Its plans and supported features are described on its own website. A FreeAppStore app does not automatically have a corresponding Pro version or a shared data migration.

Build or contribute

Get started, read the developer docs, or explore the platform source. Report app bugs and feature requests on the individual app's repository; SDK, CLI, hosting, and storefront issues belong on the platform repository.
