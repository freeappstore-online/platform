How to install apps

Every FreeAppStore app can live on your Home Screen, Dock or taskbar like a native app. No app store, no download.

Open the app first (its address is <name>.freeappstore.online, or use Open in new tab on its store page), then follow the steps for your device. It isn't limited to Chrome: Safari, Edge, Samsung Internet and others can install apps too.

Jump to: iPhone and iPad · Android · Mac · Windows · ChromeOS and Linux · After installing · Uninstalling

iPhone and iPad

Safari

  1. Tap the Share button.
  2. Tap Add to Home Screen (scroll down the list if you don't see it).
  3. If you see Open as Web App, leave it on. Then tap Add.

Chrome, Edge or Firefox

On iOS 16.4 or later, tap the Share button (in Chrome it is in the address bar), then Add to Home Screen.

Android

Chrome

  1. Tap the ⋮ menu.
  2. Tap Add to home screen, then Install. Some apps also show an Install prompt or button themselves.

Samsung Internet

Tap the ≡ menu, then Add page to → Home screen.

Edge or Firefox

Open the browser menu and choose Add to phone (Edge) or Add to Home screen (Firefox).

Mac

Safari (macOS Sonoma or later)

  1. Choose File → Add to Dock, or click the Share button and choose Add to Dock.
  2. Click Add.

The app opens in its own window, appears in Launchpad and Spotlight, and lives in the Applications folder in your home folder. It doesn't need Chrome.

Chrome

Click the install icon at the right end of the address bar, or open the ⋮ menu and choose Cast, save, and share → Install page as app. Chrome must stay installed for the app to run.

Edge

Open the ⋯ menu and choose Apps → Install this site as an app.

Windows

Edge

Open the ⋯ menu and choose Apps → Install this site as an app. Edge offers to pin the app to the taskbar and Start menu.

Chrome

Click the install icon at the right end of the address bar, or open the ⋮ menu and choose Cast, save, and share → Install page as app.

ChromeOS and Linux

In Chrome, click the install icon at the right end of the address bar, or open the ⋮ menu and choose Cast, save, and share → Install page as app. On Linux, Edge and other Chromium-based browsers work the same way.

Browsers that can't install apps

Firefox on computers doesn't install web apps as standalone apps. The apps still work in a normal Firefox tab, or you can install them from another browser on the same computer.

After installing

  • It opens like an app: its own icon and window, with no browser address bar.
  • Updates are automatic: the app loads its latest version when you open it. There is nothing to update by hand.
  • Your data may not carry over: on iPhone, iPad and Safari on Mac, an installed app keeps its own storage, separate from the browser tab. Anything saved only on the device (not to your account) starts fresh, so install before you set things up, or sign in to sync.
  • Offline depends on the app: many apps keep working offline once loaded. Sign-in, sync and live data need a connection.
  • Notifications on iPhone and iPad: apps can only send notifications after you add them to your Home Screen.

Uninstalling

  • iPhone, iPad and Android: touch and hold the app's icon, then choose Remove App or Uninstall.
  • Safari on Mac: drag the app from the Applications folder in your home folder to the Trash.
  • Chrome or Edge: open the installed app, open its menu and choose Uninstall. On Windows you can also remove it from Settings → Apps.

Desktop app (preview)

The optional FreeAppStore desktop app for Mac, Windows and Linux opens apps in their own windows and lets AI apps on your computer, like Claude Code, work in them. You don't need it to install or use apps.
