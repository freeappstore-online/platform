Platform capabilities

Services implemented by the FreeAppStore SDK and backend. Browser features and service quotas are separate.

Included platform services

Free platform

Auth

GitHub, Google, Apple, and email magic links. Connected features require sign-in. fas.auth

Free platform

Per-user KV

1 MiB per user per app, 100 keys, 64 KiB per value. Private to the app and signed-in user. fas.kv

Free platform

Public collections

Queryable documents: 10,000 per collection, 64 KiB each. Public reads; document owners control writes. fas.collections

Free platform

Shared counters

1,000 counters per app. Authenticated increments from -1,000 to +1,000. fas.counters

Free platform

Realtime rooms

32 peers per room, 64 active rooms per app, 4 KiB messages. Ephemeral messaging; no stored chat history. fas.rooms

Free platform

App-secret proxy

Five secrets and five allowlist rules per app, 10,000 app-secret requests per day. fas.proxy

Free platform

User key vault

Encrypted provider keys, injected into matching upstream requests. User-key proxy: 1,000 calls/day per user across apps. Provider charges still apply. fas.keys

Free platform

App roles and friendships

Per-app role assignment and a platform-wide friendship graph. Role management requires ownership or admin access. fas.roles / fas.friends

Free platform

Transactional email

100 sends/day per app and 50/day per sender. Requires sign-in and a configured sending service. fas.email

Free platform

Scheduled push reminders

10 devices and 20 schedules per user per app. Due reminders are checked every 15 minutes. Browser support, permission, and platform push configuration are required. fas.push

Free platform

Outbound webhooks

Five per app and 12 supported events. App owners can manage signed deliveries. fas.webhooks

Free platform

React UI and hooks

The standard Shell, PageHeader, dialogs, forms, feedback, theme controls, and hooks. @freeappstore/sdk/ui

Free platform

Static hosting

A public app repository, HTTPS subdomain, and GitHub Actions workflow that uploads your build to R2. fas publish

Free platform

Build tools

CLI scaffolding and compliance checks, MCP build/read tools, and the browser VibeCode builder. fas init / fas check

Sign-in methods, email delivery, push, and AI builds depend on configured provider credentials and browser support. An API being available in the SDK does not guarantee a provider is configured for every deployment.

Browser capabilities

Hosted apps can use the camera, microphone, location, sensors, WebAssembly, workers, local file pickers, and other browser APIs subject to browser support and user permission. See Browser APIs. Local file handling does not require a platform file-upload service.

Outside this SDK

FreeAppStore does not expose per-app server compute, direct SQL, a hosted file-upload API, arbitrary cron jobs, or custom-domain management. Apps take no payments. ProAppStore is a separate platform; check its current documentation and pricing for its capabilities.
