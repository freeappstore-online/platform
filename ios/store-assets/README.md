# Store screenshots

These are real FreeAppStore Companion simulator screenshots for the English (U.S.) listing, captured on 2026-11-28. They are listing assets, not evidence of a physical TestFlight installation or completed contribution.

## Provenance

- Runtime source: `071714ed` on `main`, with no runtime-source differences under `ios/FreeAppStore` from uploaded TestFlight source `aaa6452c`. The canonical icon was regenerated by `scripts/native-assets.mjs` before the final capture build.
- Build: local Xcode 16.0, iOS 18.0 simulator, Debug configuration, version 0.2.0, build number 55, `FAS_COMMIT=071714e`, `FAS_DEV_BUILD=YES`. It identifies itself as a development build. The TestFlight upload is separately documented in `../release/README.md`; these screenshots do not come from the distributable IPA.
- Capture device: a newly created iPhone 16 Pro simulator named **FAS Store Capture iPhone**, native portrait size **1206 × 2622**.
- The Store fetched the live public `https://freeappstore.online/registry.json`. No private account was signed in. No mock jobs, generated audio, location tracks or account fixture was injected.
- Notes and Books favourites were selected through the actual app UI. The featured carousel was moved to Math through its page control. Favourites were removed afterward for the clean overview. These are disposable local simulator preferences, not changes to a user's account.
- Navigation used the Simulator through CUA. Raw image export used `xcrun simctl io DEVICE screenshot PATH`. No UI code or screenshot-only runtime logic was added.
- The simulator status bar was normalized to 9:41, full Wi-Fi and battery using `simctl status_bar`.

Preserve these source captures; final App Store exports must remove the alpha channel and use RGB PNG/JPEG. Do not upload a raw RGBA source merely because its pixels are opaque.

Final promotional framing may add accurate captions around these screenshots. It must keep the actual screen content intact and must not manufacture features, account activity or device results. Regenerate the captioned, opaque RGB exports with `node ios/store-assets/render-listing.mjs iphone-medium` from the repository root. ## Apple requirements

[Apple's screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications), checked 2026-11-28, require medium Dynamic Island iPhone coverage. The accepted portrait size used here is 1206 × 2622. Optional large-iPhone coverage can use 1320 × 2868. Keep one to ten images per device-size set; no transparency. Verify the current upload slots and final image validation in App Store Connect.

This release is **iPhone-only**, not universal: `UIDeviceFamily=[1]` was verified in both the signed TestFlight IPA and the capture build, consistent with `TARGETED_DEVICE_FAMILY: "1"` in `ios/project.yml`. A clean iPad Pro 13-inch M4 test showed the app in iPhone compatibility mode. That diagnostic screenshot was excluded from these listing assets; it must not be represented as a native iPad layout. Apple's 13-inch iPad screenshot requirement applies if native iPad support is added in a later build.
