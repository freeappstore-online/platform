# Desktop screenshots

These are unaltered native-window captures of the publicly released, signed and notarized
FreeAppStore **1.0.0**, build **2026112801**, taken on 2026-11-28. See `provenance.json` for the
source commit, dimensions and SHA-256 hashes.

- `01-home-favourites.png`: Home with Notes, Calculator and Books in quick access, plus the
  unconnected AI setup controls. This historical capture includes the overbroad AI privacy
  sentence corrected in #865; use the Store image for current marketing.
- `02-store-favourites.png`: The live Store catalogue with those same three favourites pinned.

The app ran from the verified local notarization output with a separate `FAS_DESKTOP_USER_DATA`
directory and alternate loopback port. Favourites were selected in the actual Store UI. The
profile was signed out; contribution and automatic updates were off; no AI connections were
created and login-item management was disabled. No personal activity or app content was loaded.

CUA captured the app window after resizing it to frame the content. No screenshot was redrawn,
composited, retouched or generated. These files depict 1.0.0; the separate 1.0.1 icon release
must not be used to relabel their provenance.
